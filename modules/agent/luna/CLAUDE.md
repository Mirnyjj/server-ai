# Luna Agent Decisions

Здесь находятся Luna decision-модули для комментариев и Direct Messages.

- `comment.decision.ts` определяет действие по комментарию.
- `message.decision.ts` определяет действие по сообщению.

Luna используется как decision layer: модель получает подготовленный контекст и возвращает структурированное решение. Выполнение Instagram API действий находится ниже, в сервисах Instagram.

Нельзя считать текст ответа модели автоматически безопасным действием. Перед отправкой нужно соблюдать policy и существующие проверки агента.
