# Shared Libraries

Папка содержит небольшие инфраструктурно-независимые библиотеки общего назначения.

Сейчас основной специализированный код находится в `lib/crypto`. Новые utility-модули добавлять сюда только если они действительно используются несколькими доменами и не принадлежат конкретному модулю.

## Правила

- Не помещать сюда бизнес-логику Instagram, Telegram или AI.
- Функции должны иметь минимальное количество внешних зависимостей.
- Публичные типы должны быть явными.
- Не использовать `any`.
- Секреты и криптографические операции должны проходить через существующие сервисы, если подходящий сервис уже есть.
