# Agent Instructions

Этот файл является общим входом для coding agents, независимо от используемого инструмента или модели.

Основная проектная документация находится в корневом `CLAUDE.md` и ближайших `CLAUDE.md` внутри изменяемых директорий. Перед изменением кода агент обязан прочитать соответствующую документацию.

## Обязательное правило

Любое значимое изменение репозитория состоит из двух частей:

```
CODE CHANGE
    +
DOCUMENTATION CHANGE
    =
COMPLETE CHANGE
```

Если изменение меняет поведение, архитектуру, API, data flow, env, queue, DB schema, provider contract, agent role/tool ownership или deployment — документация должна быть обновлена в том же изменении.

Новый значимый модуль должен получить собственный `CLAUDE.md`.

Перед commit агент обязан проверить `git diff` и `git status` и убедиться, что код и документация описывают одну фактическую архитектуру.

Не оставлять устаревшую документацию рядом с новым поведением. Документировать реализацию, а не планы.

Для деталей применять правила из корневого `CLAUDE.md`.
